# Crystal Bank

Crystal Bank is a simulation fintech banking application built to demonstrate
basic digital banking operations using a modern full-stack web application.

## About

Crystal Bank allows users to create an account, log in securely, manage a
simulated bank account, and perform common banking operations.

This project is a simulation and does not involve real money or real banking
services.

## Features

- User registration and login
- Secure password hashing
- JWT authentication
- Automatic account number generation
- Account balance management
- Deposit simulation
- Withdrawal simulation
- Money transfers between users
- Transaction history
- Recent transactions
- Statement of account
- Printable statements
- Transaction receipts
- Admin account management
- Account freeze and unfreeze
- Responsive user interface

## Technologies Used

### Frontend

- React
- Vite
- Tailwind CSS
- React Router

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs

## How It Works

Users can register for a simulated bank account and log in using their
credentials.

After logging in, users can view their account number and balance and perform
deposits, withdrawals, and transfers.

Every successful transaction is stored in the database and reflected in the
user's transaction history and account balance.

Administrators can manage customer accounts and freeze or unfreeze accounts.

## Important Note

Crystal Bank is a student/project simulation.

No real money is transferred and the application is not connected to any
real banking institution.
